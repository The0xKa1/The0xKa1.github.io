# 本地验收记录

2026-09-27，macOS / Apple Silicon / Python 3.11.15 / CPU。

## 本轮升级

时间统计已替换为图像处理；增加分类边界、图片颜色压缩、零食推荐与异常检测，合计十个实验。原 Wine 分类保留为真实数据应用。地图改为点击方格编辑与 Canvas 小车回放。新增从零开始的 Windows / macOS / Linux 教程。

## 验证范围

- 58 项自动检查通过，包含十个页面的演示、未填练习、正确/错误实现、热加载、结果失效、最终评价记录。
- 行为检查包含图像滤波的收益与边缘损失、三种合成点集的非线性边界、图片调色板、推荐排除与偏好变化、异常阈值取舍、训练/验证/测试隔离，以及原有梯度更新、空簇、终止状态、不可达地图。
- 独立基础环境从 ZIP 解压运行测试；深度学习测试缺少依赖时跳过，基础实验可单独运行。
- 原完整环境已实跑 PyTorch 2.14.0、TensorFlow 2.21.0、scikit-learn 1.9.1 数字识别。
- 浏览器实测：点击格子添加墙、恢复地图、训练、下一步、播放、暂停和重置；步骤、动作、奖励与小车位置同步显示。默认地图 6 步送达。
- 网站使用 handoff 指定本地数据库导入与构建。11 个项目页面、10 张实跑预览图及 72 个文内本地引用检查有效。网站配置仍跳过 TypeScript 类型验证，因此构建成功不等于类型检查通过。
