# 图像处理工作台

坤坤给果盘拍了张照片，准备放进实验报告。照片有些暗，还带着噪点。他把画面调亮，又试着去噪，结果水果的轮廓也跟着糊了。怎样才能看清细节，又不把边缘抹掉？

![处理前后的果盘与边缘轮廓](/images/ml-guide/teaser-image.png)

帮坤坤做一张能用的实验配图。比较灰度、亮度与对比度调整、去噪和边缘提取的效果，找出适合这张照片的处理方式。除了看误差数字，也要看水果边缘和纹理还剩下多少。

## 相关知识

- [数组与形状](./python-data.md#arrays)：把图片看成像素数组，分清高、宽和颜色通道。
- [均值与方差](../basics.md#probability)：理解邻域取平均为什么能平滑噪声，也可能抹掉细节。
- [卷积与局部计算](../neural-networks.md#cnn)：认识在图片上滑动的小窗口，为理解滤波和边缘处理打基础。
- [均方误差](../linear-models.md#loss)：用像素差衡量处理前后的变化，再与肉眼看到的效果对照。
