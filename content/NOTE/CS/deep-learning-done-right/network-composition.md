# 堆叠、残差与特征融合

[基础网络](./neural-network-basics.md#forward-example)已经能把输入变成中间表示。继续处理这份表示，最直接的办法是再接一个模块，把前一个模块的输出作为新输入。但如果已有表示大部分有用，只需修正少数坐标，怎样让新增模块保留已有结果，只学习需要改动的部分？

## 顺序堆叠 {#stacking}

顺序堆叠把多个模块首尾相接，让后面的模块继续加工前面得到的特征。把输入记为 $X$，令 $H_0=X$，依次计算

$$
H_l=f_l(H_{l-1};\theta_l),\qquad l=1,\ldots,L.
$$

$H_l$ 是第 $l$ 个模块的输出，$\theta_l$ 是该模块的参数，$L$ 是模块数。整个网络为 $f_L\circ\cdots\circ f_1$，即先计算 $f_1$，再把结果依次交给后续模块。每个模块可以是一层线性变换，也可以是“卷积、归一化、激活”的组合；连接时，上一层的输出尺寸必须符合下一层的输入约定。

例如一批输入包含 $B$ 个样本，每个样本有 4 个特征，写作 $X\in\mathbb R^{B\times4}$。经过 `Linear(4,6) → ReLU → Linear(6,2)`，形状依次为 $(B,6),(B,6),(B,2)$：第一层生成 6 个特征，ReLU 改变数值，第二层再把它们组合成 2 个输出。

参数只来自两层线性变换。把各层的权重与偏置相加，参数量是 $4\times6+6+6\times2+2=44$。ReLU 保持形状不变，也没有参数。

堆叠越深，梯度传回前面的模块时经过的运算也越多。根据链式法则，深层网络的反传包含多层导数相乘。若沿某一标量路径每层导数都是 0.5，经过 10 层后的乘积是 $0.5^{10}\approx0.000977$；若都是 2，则为 $1024$。在向量表示的网络中，对应的导数写成矩阵；反复相乘同样可能使梯度缩小或增大。增加深度还可能带来更难优化的训练目标，ResNet 论文据此研究了普通网络加深后的训练误差变化。[原论文第 1、3 节](https://openaccess.thecvf.com/content_cvpr_2016/papers/He_Deep_Residual_Learning_CVPR_2016_paper.pdf)给出了比较设定。

当新增块的输入和输出同宽时，原样保留输入就能保住前面已经学到的表示。直接计算整个输出的模块，需要通过调整参数来复现输入。若另留一条路径传递输入，新增模块便可以专门计算要加上的变化。

## 残差连接 {#residual}

残差连接把输入分成两路：一路原样传递，称为恒等分支或短接；另一路计算需要添加的变化，称为主分支。更路簿保留原有针路、只在变化处添笔，对应的就是这种分工。

设块输入为 $X\in\mathbb R^{B\times d}$，其中 $B$ 是样本数，$d$ 是特征宽度。主分支 $F(X;\theta)$ 用参数 $\theta$ 计算同样形状的输出，两路逐元素相加：

$$
Y=X+F(X;\theta).
$$

主分支 $F$ 学习的是目标输出相对输入的差值，这个差值称为残差。目标映射若为 $H(X)$，分支所需表达的是 $H(X)-X$；当目标就是保留输入时，令 $F(X)=0$ 即得 $Y=X$。

相加之后的运算还会继续改变结果。假设一条输入 $x=(1,-2,3)$，主分支算出 $F(x)=(0.2,0.5,-1)$，则相加为 $(1.2,-1.5,2)$。若该块在相加后还使用 ReLU，最终输出就是 $(1.2,0,2)$。因此，判断整个块是否原样保留输入时，也要把相加后的激活算进去。

![ResNet 图 2：输入分为两路，一路经过两个权重层，一路直接连接到相加节点，之后接 ReLU](/images/deep-learning-done-right/foundations/resnet-fig2.png)

图 1：摘自 [He 等，ResNet，CVPR 2016，图 2](https://openaccess.thecvf.com/content_cvpr_2016/papers/He_Deep_Residual_Learning_CVPR_2016_paper.pdf)。裁去周围正文，保留相加后的 ReLU。图中 $F(x)$ 经过两个权重层，identity 分支直接传入 $x$。

残差相加保持特征宽度不变：两个分支都使用同一个输入，输出也都具有宽度 $d$，因此每个坐标都能找到对应的加数。恒等分支没有可学习参数，汇合处只需做逐元素加法。

这个块的参数量由主分支决定。若主分支是 $d\to m\to d$ 的两层 MLP，其中 $m$ 是中间层宽度，把两层权重和偏置加起来，共有 $dm+m+md+d$ 个参数。

恒等分支也为梯度提供了一条直接返回输入的路径。先考虑相加后没有激活的 $y=x+F(x)$，对单条样本临时采用列向量记法。令 $\ell$ 为最终的标量损失，$J_F=\partial F/\partial x\in\mathbb R^{d\times d}$ 为主分支的雅可比矩阵，记录各个输出坐标对输入坐标的导数，则：

$$
\nabla_x\ell=(I_d+J_F)^\top\nabla_y\ell.
$$

$I_d$ 是 $d\times d$ 单位矩阵，来自恒等分支对输入的导数。右侧展开后，一项是直接传回的 $\nabla_y\ell$，另一项是经过主分支的梯度；两项在输入处相加。若相加后再接 ReLU，反传需要先乘 ReLU 的激活导数，相加结果为负的位置梯度会被截断。初始化、主分支的数值尺度和归一化会影响这些路径上的梯度。

## 投影分支 {#projection}

主分支改变特征尺寸时，短接也需要做相应变换，才能逐元素相加。以图像特征为例，四个轴依次表示样本数、通道数、高和宽。若主分支把 $(B,32,28,28)$ 变成 $(B,64,14,14)$，通道数和采样网格都发生了变化。可以在短接上放一个投影 $P$，把输入变成与主分支输出相同的形状：

$$
Y=F(X)+P(X).
$$

这次投影可以用 $1\times1$ 卷积完成：它把 32 个通道组合成 64 个通道，再用步幅 stride 2 将高和宽各缩小一半。无偏置时，投影参数量为 $64\times32=2048$。

下面的卷积残差块按尺寸选择短接方式：通道数相同且步幅为 1 时原样传递，否则使用投影。主分支和投影中的 BatchNorm 用于归一化特征，后文会解释它的统计量。

```python
import torch
from torch import nn

class ResidualBlock(nn.Module):
    def __init__(self, cin, cout, stride=1):
        super().__init__()
        self.main = nn.Sequential(
            nn.Conv2d(cin, cout, 3, stride=stride, padding=1, bias=False),
            nn.BatchNorm2d(cout), nn.ReLU(),
            nn.Conv2d(cout, cout, 3, padding=1, bias=False),
            nn.BatchNorm2d(cout),
        )
        self.skip = (
            nn.Identity() if cin == cout and stride == 1
            else nn.Sequential(
                nn.Conv2d(cin, cout, 1, stride=stride, bias=False),
                nn.BatchNorm2d(cout),
            )
        )

    def forward(self, x):
        return torch.relu(self.main(x) + self.skip(x))

block = ResidualBlock(32, 64, stride=2)
x = torch.randn(2, 32, 28, 28)
y = block(x)
assert y.shape == (2, 64, 14, 14)
assert sum(p.numel() for p in block.parameters()) == 57728
```

代码中的主分支使用两个 $3\times3$ 卷积核，每对输入、输出通道之间有 9 个权重。第一层将 32 通道变为 64 通道，第二层保持 64 通道，因此两层主分支卷积分别有 $64\cdot32\cdot9=18432$ 和 $64\cdot64\cdot9=36864$ 个权重；加上短接投影的 2048 个，以及三组 BatchNorm 各 $2\cdot64$ 个可学习参数，总计 $57728$。BatchNorm 的运行均值、方差是另外保存的状态。除了代码采用的投影短接，ResNet 原论文还讨论了无参数补零短接等选择。

## 相加、拼接与门控 {#fusion}

多个分支汇合时，需要决定如何保留和组合它们的信息。残差块用相加把两路数值合到同一组坐标中；若后续模块需要分别读取两路特征，可以把它们拼接起来；若希望随输入调整各路的贡献，则可以让模型计算混合权重。

相加把两路的对应坐标合成一个数，因此要求各轴匹配，且坐标需要通过设计或训练对应起来。若 $u,v\in\mathbb R^{B\times d}$，则 $u+v$ 仍为 $B\times d$。例如 $(1,2)+(3,4)=(4,6)$，输出已将两路信息叠到同一组坐标。

拼接沿一个轴排放两路特征，让后续模块仍能分别读取它们的坐标。用 $d_1,d_2$ 表示两路的特征宽度，若 $u\in\mathbb R^{B\times d_1}$、$v\in\mathbb R^{B\times d_2}$，

$$
H=\operatorname{concat}(u,v)\in\mathbb R^{B\times(d_1+d_2)}.
$$

对于 $(1,2)$ 与 $(3,4)$，拼接结果为 $(1,2,3,4)$。拼接本身没有参数，后接 $W\in\mathbb R^{(d_1+d_2)\times m}$ 的线性层才学习如何组合两路信息，其中 $m$ 是组合后的特征宽度。

例如图像向量宽 128、数值特征宽 16，拼接后宽 144，再投影到 64 维，需要 $144\times64+64=9280$ 个参数。实现拼接时可直接用 `torch.cat([u, v], dim=-1)`，其[文档](https://docs.pytorch.org/docs/stable/generated/torch.cat.html)要求除拼接轴外其余尺寸一致。

图像特征沿通道拼接时，同一空间位置的特征会排在一起。用 $C_1,C_2$ 表示两路的通道数，$H,W$ 表示高和宽，$(B,C_1,H,W)$ 与 $(B,C_2,H,W)$ 沿通道拼接成为 $(B,C_1+C_2,H,W)$。编码器的深层特征与浅层细节可能具有不同高宽，因此要先通过上采样、裁剪或坐标对齐，让它们描述相应的空间位置。[U-Net 原论文](https://arxiv.org/abs/1505.04597)通过上采样与来自编码器的裁剪后特征拼接，将定位细节带入解码过程；原始结构的裁剪与其无补零卷积有关。

门控进一步让模型根据当前输入决定各路占比。以同形状 $u,v\in\mathbb R^{B\times d}$ 为例，先从两路特征计算权重 $\alpha$，再按坐标加权求和：

$$
\begin{aligned}
\alpha&=\sigma([u;v]W_g+b_g),\\
h&=\alpha\odot u+(1-\alpha)\odot v.
\end{aligned}
$$

$[u;v]$ 表示沿特征轴拼接，$W_g\in\mathbb R^{2d\times d}$、$b_g\in\mathbb R^d$ 生成门控，$\sigma$ 是 sigmoid，$\odot$ 是逐元素乘法。每个 $\alpha$ 坐标在 0 到 1 之间，数值越大，对应位置越偏向采用 $u$，越小则越偏向采用 $v$。若 $u=(1,2),v=(3,4),\alpha=(0.25,0.75)$，得到 $h=(2.5,2.5)$。

门控网络的参数来自 $W_g$ 和 $b_g$，共有 $2d^2+d$ 个，训练时与两路编码器共同接收最终损失的梯度。按内容为多个位置计算权重的做法见[注意力](./attention.md)。

## 归一化 {#normalization}

融合特征时，形状决定能否逐元素相加，数值尺度则影响各路对结果的贡献。两路即使形状相同，数值尺度也可能差很多。例如一路输出 $(1,3)$，另一路只是把它整体放大为 $(10,30)$，直接相加时后者贡献更大。若希望先比较每组内部的相对变化，可以先减去各自均值，再按波动幅度缩放。

归一化模块将这种处理写成统一的运算：先按指定的一组坐标计算均值和方差，再缩放、平移。对组内第 $i$ 个数值 $x_i$，有：

$$
\hat x_i=\frac{x_i-\mu}{\sqrt{v+\varepsilon}},\qquad
 y_i=\gamma_i\hat x_i+\beta_i.
$$

$\mu,v$ 是该组的均值、方差，$\varepsilon>0$ 避免分母过小，$\gamma,\beta$ 是可学习的缩放和平移。选择归一化模块时，需要确定哪些值一起计算统计量，以及预测时使用哪一份统计量。前面代码中的 BatchNorm 和序列模型常用的 LayerNorm，就在这两点上有所不同。

BatchNorm2d 对 $(B,C,H,W)$ 的每个通道，在 batch 与空间位置共 $BHW$ 个值上计算统计量。默认训练模式下用当前 batch 的均值、方差，并维护运行统计量；默认评估模式使用运行统计量。

BatchNorm2d 的可学习参数与保存的统计量按通道组织。可学习的 $\gamma,\beta$ 各有 $C$ 个元素，运行均值和方差各有 $C$ 个元素；运行统计量随训练数据更新，与优化器通过梯度更新的参数分开保存。PyTorch 训练归一化使用有偏方差估计，更新运行方差使用无偏估计；两者区别见 [BatchNorm2d 文档](https://docs.pytorch.org/docs/stable/generated/torch.nn.BatchNorm2d.html)。

LayerNorm 把一个位置内部的特征放在一起计算统计量。它常用于 $(B,T,d)$ 的序列表示，其中 $T$ 是序列长度，$d$ 是每个位置的特征宽度；均值和方差在每个样本、每个位置的最后 $d$ 个特征上计算。设 `normalized_shape=d`，则 $\gamma,\beta$ 各有 $d$ 个元素。训练和评估都根据当前输入算统计量，不需要 BatchNorm 那样的运行均值。[LayerNorm 原论文](https://arxiv.org/abs/1607.06450)与[官方实现](https://docs.pytorch.org/docs/stable/generated/torch.nn.LayerNorm.html)给出了这种归一化轴的选择。

回到本节开头的尺度例子，LayerNorm 可以把整体放大的两组特征变成相近的表示。例如一个位置的特征 $x=(1,3)$，其均值为 2、方差为 1。放大后的 $(10,30)$ 均值为 20、方差为 100；取 $\gamma=(1,1),\beta=(0,0)$，忽略很小的 $\varepsilon$ 时，两组特征的归一化结果均约为 $(-1,1)$。若用 BatchNorm，参与统计的数值来自同一通道的其他样本及位置，结果一般会不同。

确定统计范围后，还要决定归一化放在残差块的什么位置。归一化与相加的顺序会改变输出，也会改变梯度经过的路径。原始 ResNet 的常见块是 `Conv → BN → ReLU → Conv → BN → Add → ReLU`。序列模型中常见的两种排列是

$$
Y=X+F(\operatorname{LN}(X))\quad\text{（Pre-LN）},
$$

$$
Y=\operatorname{LN}(X+F(X))\quad\text{（Post-LN）}.
$$

LN 表示 LayerNorm。前者把归一化放在主分支内，短接路径直接相加；后者对相加后的结果再归一化。二者在反传中的路径不同，相关分析见 [Xiong 等，On Layer Normalization in the Transformer Architecture](https://proceedings.mlr.press/v119/xiong20b.html)。具体 Transformer block 的完整信息流由[对应章节](./transformer.md)展开。

## 残差块如何参与训练 {#training}

这些分支可以通过同一个最终损失一起训练。以前面的残差块代码为例，前向时框架记录主分支和短接的运算；反传到相加节点时，把输出梯度传给两路，再把汇到同一输入或共享参数上的梯度累加。投影短接也在计算图中，因此它的参数会和主分支一起更新。

融合方式决定梯度怎样分给各分支。拼接的反传按原分支宽度切分梯度；门控的反传沿加权求和与权重计算两条路径继续传播。只要参数参与求导、计算图保持连通，主分支、投影、门控和各编码器就能共同接收最终损失的梯度。

保存模型时，BatchNorm 的运行统计量要和参数一起保存，因为评估模式会使用这份统计量来处理新输入。`model.eval()` 与 `torch.no_grad()` 的区别见 [PyTorch 自动求导说明](https://docs.pytorch.org/docs/stable/notes/autograd.html)。
