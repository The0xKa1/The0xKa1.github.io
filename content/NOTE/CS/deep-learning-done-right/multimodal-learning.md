# 多模态学习

同一只鸟可以出现在照片、文字描述和录音中。这些输入的数值格式不同：图像是像素网格，文字先变成 token ID，声音是随时间变化的采样值。把它们送进各自的编码器后，还需要训练目标告诉模型哪些信息应当联系起来。

???quote "裁布台上的牛皮纸"
    唐师傅做了四十年衣服，这两年眼睛花了，挑布全靠手。一块料子在指头间搓两下，他就知道厚薄、软硬，攥一下回弹快不快。徒弟小秋眼睛好，隔着柜台就能分出灰蓝和铁灰，哪块有光，哪块发哑。

    两人一起接活儿就容易拧。小秋说客人要“那块发哑的灰蓝”，唐师傅去库房摸了一圈，拿回一块又厚又挺的，颜色没错，客人要的却是软的。唐师傅说要“薄、有点糙、一攥就弹回来的那种”，小秋在架子前看来看去，指不出是哪一卷。

    老板娘是唐师傅的女儿。她在裁布台上铺了一张牛皮纸，每晚收工后抽八卷布，每卷剪下两小块，在背面缝上同样颜色的线头。一块装进布袋，唐师傅只能伸手进去摸；另一块摊在小秋面前，小秋只许看，不许碰。两人各凭各的办法，把手里的布块放到牛皮纸上。

    这叫对比对齐：两种模态各用自己的编码器，靠同一事物的成对样本来训练。在一批数据里，从哪一边出发，都要在另一边的候选中找到自己的配对，正确配对的相似度调高，同批其余样本的调低。练完以后，两种表示落在同一个空间里，配对的彼此靠近。

## 对比对齐 {#contrastive-alignment}

给定一批图像及其描述，先解决“哪段文字与哪张图配对”。CLIP 用图像编码器和文本编码器分别得到向量，再以双向对比损失训练它们。[Radford 等人，2021，§2.2 与图 3](https://proceedings.mlr.press/v139/radford21a/radford21a.pdf)给出批内配对目标和实现伪代码。

设批量为 $B$，第 $i$ 对数据为 $(I_i,T_i)$。图像编码器产生 $f_i\in\mathbb R^{d_I}$，文本编码器产生 $g_i\in\mathbb R^{d_T}$。本节向量按行存储，投影矩阵 $W_I\in\mathbb R^{d_I\times d_e}$、$W_T\in\mathbb R^{d_T\times d_e}$ 将它们送到同一个 $d_e$ 维空间，然后各自作 L2 归一化：

$$
a_i=\frac{f_iW_I}{\|f_iW_I\|_2},\qquad
b_i=\frac{g_iW_T}{\|g_iW_T\|_2}.
$$

$a_i,b_i$ 均为单位行向量，分母为非零时内积就是余弦相似度；实现中用很小的正数保护零范数。把所有行堆成 $A,B_T\in\mathbb R^{B\times d_e}$，用温度 $\tau>0$ 缩放：

$$
S=\frac{AB_T^\top}{\tau}\in\mathbb R^{B\times B},\qquad
S_{ij}=\frac{a_ib_j^\top}{\tau}.
$$

$B_T$ 是文本特征矩阵，与批量标量 $B$ 区分。矩阵的行是图像，列是文本；对角线来自原始配对，其他位置是本批次的负对。CLIP 实现用可训练标量 $\alpha$ 表示逆温度 $1/\tau=\exp(\alpha)$，与两个编码器及投影一起更新。

### 双向损失 {#clip-loss}

对第 $i$ 张图，沿第 $i$ 行做 softmax，把正确文本的列号 $i$ 作为分类标签。反过来，对第 $j$ 段文本，沿第 $j$ 列做 softmax，把正确图像的行号 $j$ 作为标签：

$$
\begin{aligned}
\mathcal L_{I\to T}
&=-\frac1B\sum_{i=1}^{B}\log\frac{e^{S_{ii}}}{\sum_{j=1}^{B}e^{S_{ij}}},\\
\mathcal L_{T\to I}
&=-\frac1B\sum_{j=1}^{B}\log\frac{e^{S_{jj}}}{\sum_{i=1}^{B}e^{S_{ij}}},\\
\mathcal L&=\frac{\mathcal L_{I\to T}+\mathcal L_{T\to I}}2.
\end{aligned}
$$

两个方向各平均 $B$ 个分类损失，最后再平均。图像到文本的概率是一行内的相对概率，文本到图像的概率是一列内的相对概率；通常不能把其中一张概率表转置后当成另一张。

用两对合成数据核算。令 $B=d_e=2$，图像向量 $a_1=(1,0)$、$a_2=(0,1)$；文本向量 $b_1=(1,0)$、$b_2=(0.6,0.8)$，它们都已归一化。取 $\tau=0.5$，得到

$$
S=\begin{pmatrix}2&1.2\\0&1.6\end{pmatrix}.
$$

| 图像与文本 | 文本 1 | 文本 2 |
| --- | --- | --- |
| 图像 1 | $2$，正对 | $1.2$，负对 |
| 图像 2 | $0$，负对 | $1.6$，正对 |

图像 1 选对文本的概率为 $e^2/(e^2+e^{1.2})\approx0.689974$，图像 2 为 $e^{1.6}/(e^0+e^{1.6})\approx0.832018$。因此

$$
\mathcal L_{I\to T}\approx(0.371101+0.183901)/2=0.277501.
$$

按列计算，文本 1 选对图像的概率为 $e^2/(e^2+e^0)\approx0.880797$，文本 2 为 $e^{1.6}/(e^{1.2}+e^{1.6})\approx0.598688$：

$$
\begin{gathered}
\mathcal L_{T\to I}\approx(0.126928+0.513015)/2=0.319972,\\
\mathcal L\approx0.298736.
\end{gathered}
$$

第一张图对两段文字都有一定相似度，因而文本 2 反找图像时比图像 2 找文本更难。双向训练会对这两种混淆分别给出梯度。单个方向对分数的梯度是“预测概率减正确标签”，再除以批量；总损失还需乘两个方向平均的 $1/2$。

下面的实现中 `image_features`、`text_features` 已完成各自线性投影，形状均为 $(B,d_e)$。`log_inverse_temperature` 就是上面的 $\alpha$；训练循环应让梯度继续回到两个编码器：

```python
import torch
import torch.nn.functional as F

def clip_loss(image_features, text_features, log_inverse_temperature):
    a = F.normalize(image_features, dim=-1)
    b = F.normalize(text_features, dim=-1)
    scores = a @ b.T * log_inverse_temperature.exp()
    labels = torch.arange(scores.shape[0], device=scores.device)
    return (F.cross_entropy(scores, labels)
            + F.cross_entropy(scores.T, labels)) / 2
```

把批内其他配对当作负样本只是一种约定。两张照片若是同一种鸟、描述也都正确，把非对角位置一概压低就会产生假负样本。重复文本、同一图像的多个描述以及过小的批量都会影响训练信号，可以靠数据组织或多正例目标处理。$B=1$ 时两次 softmax 都只有一个候选，损失恒为零。

### 检索与分类 {#cross-modal-retrieval}

检索时可预先编码候选图像，用查询文本的向量逐个打分，返回最高分的图像。零样本分类则把候选类别写成文本描述，编码后与图像比较；新增类别可改变候选文本集合，而不必立即增加一个固定类别输出层。“零样本”是说没有用这次分类任务的训练标签继续拟合，模型依赖的仍是先前的图文训练。

CLIP 的直接输出是相似度。若词库只有“鸟”和“铃铛”，它只能在这些候选中排序，不能凭这个矩阵产生一句“左边有两只鸟”。候选集合一变，softmax 概率也会变，检索给出的高相对概率并不是陈述为真的概率。

要生成回答，需要把图像信息接入一个预测下一个文本 token 的模型，并用对应的语言生成目标训练这条路径。

## 视觉 token 与连接器 {#visual-tokens}

一张全局图像向量适合做整体匹配，但回答“左边是什么”需要保留不同位置的特征。以 [LLaVA 原论文 v2 §4.1](https://arxiv.org/html/2304.08485v2#S4.SS1)的路径为例：取 CLIP 视觉编码器的网格特征，经过可训练线性连接器，形成与语言嵌入同宽的视觉 token，再交给语言模型。这里只用 CLIP 的视觉编码器，前面的相似度矩阵不参与生成答案。

以下是一组用于复算的配置：批量 $B=2$，输入 RGB 图像缩放到 $224\times224$，视觉 patch 为 $14\times14$，视觉宽度 $d_v=1024$，语言宽度 $d_l=4096$，词表大小 $V=32000$，对应 ViT-L/14 加语言解码器的连接方式。

每张图有 $N_v=(224/14)^2=256$ 个 patch；每块含 $3\cdot14^2=588$ 个像素分量。共享的线性 patch 投影把 $(B,256,588)$ 变成 $(B,256,1024)$。视觉编码器还加入位置编码；若实现包含一个 CLS token，内部长度会是 257。本例在输出网格特征时去掉 CLS，保留 $(2,256,1024)$。

记网格特征为 $Z_v$，连接器采用无偏置线性投影 $W_P\in\mathbb R^{1024\times4096}$：

$$
H_v=Z_vW_P\in\mathbb R^{2\times256\times4096}.
$$

$W_P$ 有 $1024\cdot4096=4194304$ 个可训练参数；若实现带偏置，还要加 4096 个。连接器调整特征通道的含义，但保留 256 个位置。每个视觉 token 是连续的 4096 维向量，无需先选一个词表 ID。

例如把宽度缩成 $d_v=2,d_l=3$，单个网格向量 $z=(1,2)$ 与

$$
W_P=\begin{pmatrix}1&0&1\\0&1&-1\end{pmatrix}
$$

相乘得到 $h=(1,2,-1)$。

### 进入语言模型 {#multimodal-sequence}

将系统提示、用户问题和必要的角色分隔符编码为 $L_q=20$ 个文本 token ID，查语言嵌入表 $E\in\mathbb R^{V\times4096}$ 得到 $(2,20,4096)$。本例把视觉 token 放在文本之前：

$$
H_{\mathrm{prefix}}=[H_v;H_q]
\in\mathbb R^{2\times276\times4096}.
$$

分号表示沿序列轴拼接。20 已含本例所需的文本特殊标记，额外的图像起止标记也要计入长度。对话模板也可以把图像放在用户文本中间，长度和标签位置随之改变。

| 步骤 | 张量形状 | 信息或运算 |
| --- | --- | --- |
| 图像输入 | $(2,3,224,224)$ | 连续像素 |
| patch 展开 | $(2,256,588)$ | 256 个空间块 |
| 视觉编码器输出网格 | $(2,256,1024)$ | 已结合图像上下文的特征 |
| 连接器 | $(2,256,4096)$ | 与语言模型输入宽度相同 |
| 文本 ID 查嵌入 | $(2,20,4096)$ | 系统与问题等文本 |
| 拼接前缀 | $(2,276,4096)$ | 视觉与文本占不同序列位置 |
| 因果语言模型 | $(2,276,4096)$ | 后面的位置可使用前面的视觉信息 |
| 词表线性层 | $(2,276,32000)$ | 每个位置预测下一个文本 token |
| 首次生成取末位置 | $(2,32000)$ | softmax、选择 token ID、追加输入 |

语言模型的词表投影为 $W_O\in\mathbb R^{4096\times32000}$，因此末层隐藏状态乘 $W_O$ 得到词表 logits。每次只用当前末位置预测下一 token，选择后查嵌入表，追加到序列中继续解码；输出 ID 最终由 tokenizer 解码为文字。视觉编码和连接器通常在一次图像输入时计算一次，其结果进入前缀的 KV cache，后续步骤复用缓存。

视觉编码器内部是图像块之间的双向注意力。进入本例的因果语言模型后，各位置只访问其左侧和自身；所有问题和回答位置都在视觉前缀之后，因此可以访问全部视觉 token。视觉 token 已由视觉编码器结合过整张图的上下文。带 padding 的批次还要屏蔽填充位置。

尺寸接上只说明运算可执行。若连接器随机初始化，语言模型并不知道这些新向量怎样对应对象和空间关系；训练需要让答案损失经过语言模型传回连接器。

## 视觉指令学习 {#visual-instruction}

一条训练样本应包含图像 $I$、问题或指令 $q$、目标回答 $y$。例如图像中有两只鸟，问题是“左边那只是什么颜色？”，回答是“蓝色。”。同一图像也可以配计数或整体描述问题，这些问题选择了图像中的不同信息。只有“图像加描述”的样本，不能充分覆盖这些请求。

LLaVA v2 §3 使用图像描述与边界框等符号信息，让当时的纯文本教师生成对话、详细描述和推理数据。教师看到的是这些文字与框标注，未直接看到像素；产生的指令需要审查是否超出标注所能支持的内容。[原文 §3、§4.2](https://arxiv.org/html/2304.08485v2#S3)还区分了连接器预训练与指令微调：

| 阶段 | 数据和预测目标 | 视觉编码器 | 连接器 | 语言模型 |
| --- | --- | --- | --- | --- |
| 连接器预训练 | 图文对转成描述请求，预测描述 | 冻结 | 更新 | 冻结 |
| 视觉指令微调 | 图像、问题、回答，预测助手回答 | 冻结 | 更新 | 更新 |

这是原始 LLaVA 的方案，其他方案也有解冻视觉编码器或改用多层连接器的。第一阶段虽然冻结语言模型权重，仍需要保留从回答损失经过语言模型到视觉输入的梯度；把整个语言模型前向包进 `no_grad()` 会切断连接器的学习路径。冻结的视觉编码器位于可训练连接器之前，可以预计算其输出特征。

### 回答损失与掩码 {#visual-answer-loss}

训练时把真实回答也放入序列，使用 teacher forcing。设回答及停止标记共 $L_a=8$ 个 token，本例总长度为 $256+20+8=284$，隐藏状态和 logits 分别为 $(2,284,4096)$、$(2,284,32000)$。在移位后的下一 token 标签中，只对助手回答及其停止标记计损失；视觉位置、用户问题、系统消息和 padding 的标签均忽略。

令 $m_{b,k}\in\{0,1\}$ 标记批次样本 $b$ 中第 $k$ 个移位标签是否应训练，$y_{b,k}$ 为该标签 ID，$\ell_{b,k}\in\mathbb R^V$ 为预测它的 logits。采用有效回答 token 整体平均：

$$
\mathcal L_{\mathrm{answer}}=
-\frac{1}{\sum_{b,k}m_{b,k}}
\sum_{b,k}m_{b,k}
\log\operatorname{softmax}(\ell_{b,k})_{y_{b,k}}.
$$

标签的移位必须配合输入位置：最后一个问题位置的 logits 预测回答的第一个 token；第一个回答位置的 logits 预测第二个回答 token。网络看到的真实回答只在因果遮罩允许的前缀里，不得看到正在预测的 token。多轮对话中可对各轮助手回答计损失，用户轮保持忽略。

若一个回答只有两个被监督 token，其目标概率为 $0.8$ 和 $0.5$，则平均损失为 $(-\log0.8-\log0.5)/2\approx0.458145$。假如另有 20 个问题 token 被忽略，分母仍为 2。把分母误写成整段长度会让较长问题稀释相同回答的训练信号。

对一般图像，训练不要求每个视觉 token 都有一个人工对象标签。答案中的词会通过注意力把梯度传到所用的视觉特征。这个监督也可能允许模型靠语言先验猜答案，例如总是把“天空是什么颜色”答成“蓝色”；是否真的使用图像，需要在评价中检验。

## 评价问题 {#multimodal-evaluation}

检索和生成回答的输出不同，评价也应分开。检索先固定候选库，用 Recall@K 检查正确配对是否进入前 $K$ 名，并说明一个查询是否允许多个正确配对。回答任务需要可检查的答案或事实单元：计数看数字，空间关系看对象及左右顺序，描述则逐项核对所述对象是否存在。

下面是一组评价设计：

| 输入变化 | 固定的问题 | 核对内容 |
| --- | --- | --- |
| 同场景从两只鸟改为三只 | “共有几只鸟？” | 答案是否随数量改变 |
| 交换红杯与蓝杯的左右位置 | “左边杯子是什么颜色？” | 颜色词是否随空间关系改变 |
| 图中没有狗，问题暗示“这只狗” | “这只狗在哪里？” | 是否指出图中未见狗，而非编造位置 |
| 同问题换成不相关图或移除图像 | 保持文字完全一致 | 正确率下降和答案变化，作为视觉依赖的诊断 |
| 缩小图片导致小字不可辨 | “标签写了什么？” | 是否说明无法辨认，是否凭常见文字补全 |

移除图像会改变输入分布，因此它是诊断对照，需要和原图、替换图的结果一起解释。为防止训练记忆混入评价，应按原始图像及其近重复分组划分数据，不能把同一张图的不同问法随机散进训练集和测试集。合成指令还需检查答案是否包含教师从文字描述之外补出的细节。

裁剪掉目标物体、连接器没学会传递位置、语言模型忽略图像，都可能产生相同的错误答案；逐步查看预处理后的输入、对照问题与生成结果，才能确定下一步应改数据、表示还是训练范围。任务指标的选择与划分原则见[评价与泛化](./evaluation-and-generalization.md)。
