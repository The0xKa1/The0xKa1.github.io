# Transformer

同样三个 token 换个顺序，含义可以改变。注意力若只比较 token 的内容，就缺少判断先后顺序的依据。续写训练还面临另一个问题：完整句子已在训练文件里，怎样避免当前位置偷看自己要预测的后文？

???quote "饺子卡片"
    小满家包饺子的步骤写在一叠卡片上：和面、醒面、拌馅、擀皮、包、烧水、下锅、点三次凉水。奶奶说，今年年三十由她掌勺，之前要把整套背熟。

    卡片掉在地上散过一回。小满捡起来一数，八张都在，哪张在前却说不清了。她凭“有哪几样”来排，排出了先下锅再烧水。奶奶拿笔在每张卡片右上角写了序号，以后怎么洗乱，都能按号排回去。同一张“下锅”，排在第七和排在第二，意思完全两样。

    ![女孩用纸板盖住桌上一排卡片的右半边](/images/deep-learning-done-right/stories-v2/C02.png)

    序号没有挡住后面的卡片，纸板也没法把散乱的顺序排回来，两样东西各管一件事。在 Transformer 里，前一件叫位置编码，后一件叫因果 mask。

Transformer 用一层层重复的计算块（block）更新序列表示。每层先通过注意力从其他位置取信息，再用前馈网络变换每个位置的特征；残差连接保留已有表示，归一化调整特征的数值尺度。输入端补上位置信息，输出端把最后一层的表示转成预测，便组成了完整模型。

算例取批量 $B=2$、序列长 $T=3$、模型宽度 $d=8$、头数 $h=2$、前馈宽度 $d_{ff}=16$；这些是教学尺寸，原论文 base 模型使用 $d=512,h=8,d_{ff}=2048$。

图 1：[Attention Is All You Need，图 1](https://arxiv.org/abs/1706.03762)，裁自 PDF 第 3 页。沿箭头从下往上读。左侧输出进入右侧中间的注意力层；“$N\times$”表示堆叠多层，通常每层参数独立。

## 嵌入与位置编码 {#position}

嵌入表先把 token ID 转成内容向量。设词表大小 $V=10$，输入 ID 张量的形状为 $(2,3)$，表示 2 条序列、每条 3 个 token。每个整数 ID 索引嵌入表 $E\in\mathbb R^{10\times8}$ 的一行，查表后得到形状为 $(2,3,8)$ 的向量序列。

内容向量还需要带上位置，才能区分同一个 token 出现在句首还是句尾。这相当于给步骤卡片写上序号：卡片内容与所在位置一起参与后续判断。原论文将位置编码与嵌入逐元素相加：

$$
X^{(0)}_{b,t,:}=\sqrt d\,E[\mathrm{id}_{b,t}]+P_{t,:}.
$$

式中 $b$ 表示样本，$t$ 表示序列位置，$X^{(0)}$ 是送入第一层的表示。$P\in\mathbb R^{T\times d}$ 为每个位置提供一个宽度为 $d$ 的向量；沿批量广播意味着同一位置的所有样本使用同一个位置向量。嵌入乘以 $\sqrt d$ 是原论文的约定。

固定正弦位置编码用不同频率的正弦和余弦生成位置向量。位置从 0 开始，具体写成

$$
\begin{gathered}
P_{t,2i}=\sin\left(\frac{t}{10000^{2i/d}}\right),\\

P_{t,2i+1}=\cos\left(\frac{t}{10000^{2i/d}}\right),\\

0\le i<d/2.
\end{gathered}
$$

$i$ 索引通道对，各对使用不同频率。对 $d=8$，分母依次为 $1,10,100,1000$。位置 0 的向量为 $[0,1,0,1,0,1,0,1]$；位置 1 的前四个分量约为 $[0.8415,0.5403,0.0998,0.9950]$，后四个约为 $[0.0100,1.0000,0.0010,1.0000]$。相同 token 出现在不同位置时，加到它上面的向量不同。

位置向量可以按公式生成，也可以通过训练学习。固定正弦表没有训练参数；若改用最大长度为 $T_{max}$ 的可学习位置表，则增加 $T_{max}d$ 个参数。[原论文 §3.5](https://arxiv.org/abs/1706.03762)描述了这两种选择。

## 编码器层 {#encoder-block}

编码器层把注意力取回的信息融入当前位置的表示。它先通过残差连接把新信息加回输入，再在每个位置内部做非线性变换；两个步骤都配合归一化，组合方式沿用[残差与归一化](./network-composition.md)。

图中的 Post-LN 结构在每次残差相加之后做 LayerNorm（LN）。省略 dropout 运算时，一个 block 为

$$
\begin{gathered}
U=\operatorname{LN}_1\bigl(X+\operatorname{MHA}(X,X,X)\bigr),\\

Y=\operatorname{LN}_2\bigl(U+\operatorname{FFN}(U)\bigr).
\end{gathered}
$$

多头注意力 MHA 的三个输入依次产生查询 Q、键 K、值 V。编码器的自注意力让它们都来自本层输入 $X$，因此每个位置都从同一条序列中取信息。第一次残差相加和归一化得到 $U$，再经过 FFN、第二次残差相加和归一化得到 $Y$，交给下一层。两个 LN 分别有自己的参数。

实际训练在每个子层输出加回残差之前应用 dropout；推理关闭 dropout。

每个子层最终都恢复模型宽度，才能逐元素加回残差。教学算例中，$X,U,Y$ 全是 $(2,3,8)$，中间张量的变化如下：

| 位置 | 操作 | 输出尺寸 |
| --- | --- | --- |
| 输入 | 嵌入与位置编码相加 | $(2,3,8)$ |
| QKV 投影 | $(8,24)$ 权重加 $(24,)$ 偏置 | $(2,3,24)$ |
| 拆分与转轴 | 2 个头，每头宽 4 | Q、K、V 各 $(2,2,3,4)$ |
| 自注意力 | 缩放点积、mask、softmax、乘 V | $(2,2,3,4)$ |
| 拼头与输出投影 | 合并为宽 8，再乘 $(8,8)$ | $(2,3,8)$ |
| 残差与 LN | 与输入逐元素相加，按通道归一化 | $U:(2,3,8)$ |
| FFN 第一层 | $(8,16)$ 权重及 $(16,)$ 偏置，再 ReLU | $(2,3,16)$ |
| FFN 第二层 | $(16,8)$ 权重及 $(8,)$ 偏置 | $(2,3,8)$ |
| 残差与 LN | 与 $U$ 相加并归一化 | $Y:(2,3,8)$ |

### 逐位置前馈网络 {#ffn}

前馈网络把注意力汇聚的信息进一步加工成新特征。注意力通过加权组合 value 交换各位置的信息，FFN 则在每个位置内部混合通道，并加入非线性变换。它对所有位置使用同一套两层网络，先扩宽通道，再投回原宽度，序列长度保持不变。

原论文的 position-wise FFN 是

$$
\operatorname{FFN}(u)=\operatorname{ReLU}(uW_1+b_1)W_2+b_2.
$$

$u$ 为宽度 $d$ 的行向量；$W_1:(d,d_{ff})$、$b_1:(d_{ff},)$、$W_2:(d_{ff},d)$、$b_2:(d,)$。同一层所有位置共享这些权重，各位置独立计算；跨位置的信息交换发生在注意力中。ReLU 让两次线性变换之间产生非线性，第二个线性层恢复宽度，使输出能与残差相加。

用更小的 $d=2,d_{ff}=3$ 单独验算。令 $u=[1,-2]$，偏置为零：

$$
\begin{gathered}
W_1=\begin{bmatrix}1&0&1\\0&1&-1\end{bmatrix},\\

W_2=\begin{bmatrix}1&0\\0&1\\1&-1\end{bmatrix}.
\end{gathered}
$$

第一层将输入扩展为 $[1,-2,3]$，ReLU 把负分量置零，得到 $[1,0,3]$。第二层把它投回宽度 2，输出 $[4,-3]$；再加上原输入 $u$，残差相加的结果为 $[5,-5]$。

### LayerNorm {#layernorm}

LayerNorm 在每个位置内部调整特征的数值尺度。它先减去该位置各通道的均值，再除以“方差加上稳定项后开方”的结果，最后用可学习的缩放和平移调整输出。对某个样本、某个位置的向量 $u\in\mathbb R^d$，计算为

$$
\begin{gathered}
\mu=\frac1d\sum_{j=1}^d u_j,\\

s^2=\frac1d\sum_{j=1}^d(u_j-\mu)^2,\\

\operatorname{LN}(u)_j=\gamma_j\frac{u_j-\mu}{\sqrt{s^2+\epsilon}}+\beta_j.
\end{gathered}
$$

均值 $\mu$ 和方差 $s^2$ 沿该位置的特征轴计算；$\gamma,\beta\in\mathbb R^d$ 分别控制逐通道的缩放和平移，$\epsilon>0$ 防止除零。

以两个通道为例，对 $u=[1,3]$，$\mu=2,s^2=1$，若 $\gamma=[1,1],\beta=[0,0]$ 且暂忽略很小的 $\epsilon$，输出为 $[-1,1]$。LayerNorm 每次都用当前向量的统计量，不需要 BatchNorm 那样的运行均值。参见[Layer Normalization 原论文](https://arxiv.org/abs/1607.06450)。

归一化放置的位置决定了子层接收什么表示。前面的 Post-LN 先做子层计算和残差相加，再归一化；常见的 Pre-LN 则先归一化输入，再送入注意力或 FFN：

$$
\begin{gathered}
U=X+\operatorname{MHA}(\operatorname{LN}_1(X)),\\

Y=U+\operatorname{FFN}(\operatorname{LN}_2(U)).
\end{gathered}
$$

Pre-LN 公式把 MHA 简写成单输入形式，Q、K、V 都由归一化后的输入产生，堆栈末尾通常再接一次 LN。两种结构的归一化位置改变了残差路径和梯度行为；[Xiong 等人的分析](https://arxiv.org/abs/2002.04745)专门比较了它们。

### 参数量 {#parameters}

参数量可以按注意力、FFN 和归一化分别核算。回到 $d=8,d_{ff}=16$ 的教学模型，每个带偏置编码器 block 中，Q、K、V 投影和输出投影各有一组权重与偏置，多头注意力因此有 $4d^2+4d=288$ 个参数；FFN 有 $dd_{ff}+d_{ff}+d_{ff}d+d=280$ 个；两个 LN 各有 $2d=16$ 个，共 32 个。合计 $288+280+32=600$ 个。

序列长 3 变为 30，block 参数仍为 600，但激活和注意力计算增多。堆两层且不共享权重，就是 1200 个 block 参数。它们与嵌入表的 80 个参数、任务输出头分开计数。

计算时保存的中间结果也要与模型参数区分。RNN 用单个递归隐藏状态逐步传递信息；普通 Transformer 在全序列前向中保存各层激活，生成时还可用各层的 KV cache 保存历史位置的键和值。

## 编码器与解码器 {#architectures}

编码器适合根据完整输入形成表示，因为它的自注意力通常能访问整条序列的有效位置。做文本分类时，可以取专门的汇聚 token 的表示，或对有效位置的表示求平均，得到每个样本的一个向量。设类别数为 $C$，接上 $(d,C)$ 分类权重后，就得到 $(B,C)$ 的类别分数（logits）。

原论文的解码器每层有三个子层：带因果 mask 的目标端自注意力、查询源端表示的交叉注意力、FFN。交叉注意力里 Q 来自本层目标表示，K、V 来自最后一层编码器输出。

交叉注意力的分数矩阵要让每个目标位置对应所有源位置。若源长 $S=5$、目标长 $L=3$，均宽 8，两个头的交叉分数是 $(2,2,3,5)$，汇聚并拼头后回到 $(2,3,8)$。因果约束加在目标自注意力上；翻译时整句源文本已知，目标每步可看全部有效源位置。[原论文 §3.1 与 §3.2.3](https://arxiv.org/abs/1706.03762)给出了这一信息流。

按是否保留编码器、是否读取源端表示，可以把模型组织成三种常用结构：

| 结构 | 可见信息与输出 | 训练任务例子 |
| --- | --- | --- |
| Encoder-only | 每个输入位置访问双向上下文 | 掩码 token 预测、整句分类 |
| Encoder-decoder | 源端双向编码，目标看过去及源端 | 翻译、条件文本生成 |
| Decoder-only | 每个位置只访问自身和更早位置 | 下一 token 预测 |

Decoder-only 只堆叠因果自注意力和 FFN，没有源端交叉注意力子层。它采用的序列概率分解与生成顺序见[自回归条件预测](./rnn.md#conditional-sampling)，更一般的生成目标见[自回归模型](./generative-models.md#autoregressive)。

## 训练目标 {#training}

[条件概率与采样](./rnn.md#conditional-sampling)给出了“真实前缀训练、已有前缀生成”的接口，Transformer 堆栈也用来计算这一条件分布。训练材料虽然包含完整句子，每个位置的预测仍须只依赖它之前的目标 token。因果 mask 就像练背卡片时盖住后文的纸板：它屏蔽后续输入位置的注意力分数，使这些位置的注意力权重为零。

设一条目标序列为“我、爱、猫、EOS”，EOS 为结束标记。取长度 4 的训练输入 `[BOS, 我, 爱, 猫]`，标签为 `[我, 爱, 猫, EOS]`；BOS 表示开始。输入和标签错开一位，配合因果 mask，输入位置 $t$ 只能根据目标前缀预测该位置的标签。例如输入“爱”的位置可以读取 `[BOS, 我, 爱]`，用这些信息预测标签“猫”。

最后一层隐表示为 $(B,4,d)$，乘词表输出矩阵 $W_{\mathrm{vocab}}\in\mathbb R^{d\times V}$ 并加偏置，得到 $(B,4,V)$ logits。沿词表做 softmax，再对有效标签取负对数平均：

$$
\begin{gathered}
\ell_{b,t}=-\log p_\theta(y_{b,t}\mid y_{b,<t},c),\\
\mathcal L=\frac1{N_{\mathrm{valid}}}\sum_{b,t}m_{b,t}\ell_{b,t}.
\end{gathered}
$$

式中 $y_{b,t}$ 是样本 $b$ 在位置 $t$ 的目标 token，$y_{b,<t}$ 是它之前的目标前缀，$c$ 表示源端条件输入；decoder-only 省去源端条件。$\ell_{b,t}$ 是单个位置的负对数似然。掩码 $m$ 在有效目标位置取 1，在填充位置取 0；$N_{\mathrm{valid}}$ 是整个批次的有效 token 数，因此损失按有效目标位置平均。

单个位置的损失由正确标签的概率决定。若词表大小为 4，某位置 logits 为 $[0,\log2,0,0]$，softmax 为 $[0.2,0.4,0.2,0.2]$，标签为第二类时损失是 $-\log0.4\approx0.9163$。实现交叉熵时通常直接传 logits，库内部用稳定的 log-softmax。

训练时，损失沿整个计算图反向传播，更新嵌入、投影、FFN、归一化和输出头。原论文还用了标签平滑（label smoothing）与学习率预热（warmup）；本节算例采用未平滑的目标标签。

训练时所有位置的真实前缀都已包含在输入张量中，因此配合因果 mask，各位置的预测可在一次前向中并行计算。

推理时，后续输入要等前一步生成后才能得到。模型只知道当前前缀，要取最后位置的 logits 产生一个 token，再把它追加到前缀，重复直到 EOS 或长度上限。

选取新 token 时，可以直接取概率最大的一个，这称为贪心选择。也可以采用温度采样：令最后位置的 logits 向量为 $o$，先算 $\operatorname{softmax}(o/\tau)$，$\tau>0$，再随机抽取，较小温度让分布更集中。

## KV cache {#kv-cache}

逐步生成会反复用到历史位置的键和值，把它们缓存下来可以减少重复计算。因果约束保证旧位置看不到新位置，所以追加 token 后，旧位置在各层产生的 K、V 保持不变。

KV cache 为每层分别保存这些 K、V。第一次处理整个提示称为 prefill（预填充）；之后每步仅计算新 token 的 Q、K、V，把新 K、V 接到该层缓存，再用新 Q 查询全部缓存。[Hugging Face 的官方缓存说明](https://huggingface.co/docs/transformers/cache_explanation)给出了这一过程。

缓存沿序列长度方向增长，每一步的查询只来自新位置。用 $B=2,h=2,d_k=d_v=4$ 的标准多头模型，其中 $d_k$ 和 $d_v$ 分别是每个头的键和值的宽度。已经缓存 3 个位置时，每层 K、V 各为 $(2,2,3,4)$。新 token 的 Q、K、V 各为 $(2,2,1,4)$；追加后缓存为 $(2,2,4,4)$，新 query 的注意力分数为 $(2,2,1,4)$。只需要新位置的输出，不再重算历史位置。

缓存占用随层数、批量和序列长度增长。设模型有 $N$ 层，已缓存长度为 $T$，标准缓存共存 $2NBTd$ 个标量，前面的 2 来自 K 与 V。教学模型若 $N=2,B=2,T=3,d=8$，就是 192 个标量，float32 占 768 字节；生成一个 token 后增到 256 个标量。缓存省掉了重复投影和历史计算，新 query 仍要与不断增长的历史 key 交互。

位置旋转、归一化与门控前馈的组合见[现代 Transformer](./modern-transformer.md#decoder-block)；缓存按头共享的形状与字节核算见[分组查询注意力](./efficient-sequence-models.md#grouped-query)。
